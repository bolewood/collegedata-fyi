Methodology

Each station writes a public heartbeat when it starts and when it finishes. Lamps are computed at read time. If the scheduled heartbeat is older than the SLA, the lamp is red — including when a manual run succeeded yesterday. Missing data is red, not gray.

Locked doors use probe outcomes plus a short public override list for Tableau and SharePoint IRM. We do not publish stack traces, seed URLs with tokens, or operator notes.
