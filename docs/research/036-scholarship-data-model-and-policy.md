# PRD 036 research: record model, sourcing policy, refresh cadence

Research for [PRD 036](../prd/036-named-scholarship-directory.md). Produced 2026-11-08 by a GPT-6.1-Sol research worker (Orca). Read-only web research; every claim links its source. Third-party directories are cited as leads only.

Research complete: scholarship taxonomy and operating policy
I completed the read-only repository review and web research of more than 20 official institutional pages, concentrating on record semantics and operating policy rather than building a seed list or surveying directories.
My structured findings and recommendations, observed 2026-11-08, are as follows:

**A — Main recommendation and repository fit**

Maintain one stable logical program per institution and published program name, with immutable cohort-specific term versions, residency or tier variants, and separately modeled benefit components; publish factual extraction plus original editorial synthesis with field-level official-source provenance, an explicit entry cohort, a last-human-verification date, and a visible unknown/conflict state; treat yearly refresh as the minimum full review, supported by inexpensive change monitoring during the application cycle

Repository context reviewed: CLAUDE.md, docs/ARCHITECTURE.md, docs/prd/018-open-college-fit-data.md, data/discovery/README.md; also checked the implemented merit view, current canonical schema, and public methodology; the architecture already supplies institution_directory, institution_slug_crosswalk, school_merit_profile, source SHA/version patterns, and reviewed change events; reuse these identity and provenance conventions while keeping named-program observations separate from CDS aggregate observations

Licensing precedent: data/discovery/README.md explicitly separates CC BY-SA 4.0 content from MIT consumer code and requires a signed contribution agreement for outside content contributions; a scholarship content directory should make the same boundary explicit and decide whether to adopt that contribution gate, without assuming the discovery directory's rule automatically applies elsewhere

**C — Proposed record contract: concrete names, types, enums**

Recommended storage: scholarship_programs for stable identity; scholarship_program_versions for entry-cohort facts; scholarship_offers for residency/tier alternatives; scholarship_benefits for components; scholarship_sources and scholarship_field_evidence for provenance; scholarship_change_reviews for publication decisions; a convenient API can nest these beneath one program record

Identity/version fields:
- program_id: UUID, stable through rename and URL migration
- school_id: text, canonical existing school slug; ipeds_id: integer, matching institution_directory; applicable_campus_ids: integer[]; campus_notes: text|null
- official_name: text; aliases: text[]; administering_unit: text|null; program_family: stamps|national_merit|presidential|honors|other|null, a classification rather than an identity
- awarding_authority: institution|affiliated_foundation|cofunded|external|unknown; funder_types: array of institution|foundation|state|nmsc|corporate|other|unknown
- version_id: UUID; entry_year: integer|null; entry_terms: array of fall|spring|summer; award_offer_year: text|null; aid_academic_year: text|null; effective_from/effective_to: date|null; source_cohort_text: text
- program_status: active|paused|discontinued|unknown; application_status: not_open|open|closed|unknown, separate from existence; verification_status: verified|needs_review|conflicting|historical_only|unverified; supersedes_version_id: UUID|null
- applicant_types: array of first_time_first_year|transfer|continuing_undergrad|graduate_transition; degree_level: undergraduate; exclude ordinary graduate awards even when unused undergraduate terms can later support graduate study
- related_programs: array of {program_id, relation: component_of|includes|replaces|mutually_exclusive_with|successor_to}; deduplicate named constituent awards and marketed bundles

Offer/selection fields:
- offer_id: UUID; variant_name: text|null; residency_variant: in_state|out_of_state|international|any|other|unknown
- selection_mode: automatic_guaranteed|competitive|hybrid|unknown; automatic_guaranteed only with explicit official promise plus all conditions
- consideration_route: admission_application|separate_application|honors_application|nomination|invitation|multiple|unknown
- nomination_policy: required|optional|not_used|unknown; nominator_types: array of school|counselor|self|institution|other; nomination_geographies/school_networks: text[]
- aid_basis: merit_only|merit_and_need|need_only|unclear; need_role: required|considered|not_considered|top_up_only|unknown; need_definition: text|null; no automatic mapping from a required FAFSA to demonstrated need
- selection_criteria: array of academics|leadership|service|art|music_drama|job_skills|research|other; criteria_notes: text
- funds_limited: boolean|null; guarantee_scope: all_eligible_admits|selected_recipients_only|unknown; admission_required: boolean|null

Eligibility fields:
- eligibility_rules: expression tree with all/any/not plus typed predicates, enabling GPA AND (ACT OR SAT), resident-specific branches, exceptions and component-specific rules without flattening logic
- national_merit_statuses: array of semifinalist|finalist|scholar; first_choice_required: boolean|null; first_choice_deadline_id: UUID|null; corporate_or_nmsc_award_exclusions: text|null
- gpa_min/gpa_max/gpa_scale: decimal|null; gpa_basis: weighted|unweighted|core_recalculated|institution_defined|unknown; gpa_as_of: end_junior_year|graduation|other|unknown; gpa_notes: text
- tests_policy_for_scholarship: required|optional|not_considered|optional_with_separate_tiers|unknown; test_rules: array of {exam: ACT|SAT|PSAT_NMSQT|other, minimum: number|null, maximum: number|null, scoring: single_sitting|superscore|other|unknown, official_scores_required: boolean|null, exam_version: text|null, required_sections: text[], deadline_id: UUID|null}
- residency_eligible: array of in_state|out_of_state|international; citizenship_eligible: array of us_citizen|permanent_resident|eligible_noncitizen|international|other; geographic_rules: typed state/county/country include/exclude arrays plus text exceptions; do not equate citizenship with tuition residency
- majors_allowed/majors_excluded: text[]; colleges_allowed: text[]; cips_allowed: text[] optional reviewed crosswalk, retaining official text; major_change_restrictions: text|null; modality: array of campus|online|hybrid; honors_requirement: admission_required|participation_required|award_confers_admission|none|unknown
- first_generation_rule: {role: required|preferred|considered|not_considered|unknown, definition: text|null}; same role/definition pattern for low_income, service, school affiliation and other qualitative criteria
- enrollment_min_credits: decimal|null; prior_college_credit_limit: decimal|null; gap_year_policy: text|null; first_degree_required: boolean|null; eligibility_exceptions: text[]

Benefit/amount fields:
- benefits: array of {benefit_id: UUID, category: tuition|mandatory_fees|college_program_fees|housing|meals|books_supplies|laptop|personal_stipend|transportation|health_insurance|research|study_abroad|enrichment|other, instrument: scholarship_credit|cash_stipend|tuition_waiver|reimbursement|restricted_fund|earned_compensation|in_kind|unknown, coverage: full|partial|fixed_amount|percentage|variable|unknown, amount: Amount|null, scope_text: text, exclusions: text[], eligible_terms: enum[], duration_terms: integer|null, funding_guarantee: guaranteed|conditional|unknown, paid_to: student|student_account|vendor|unknown}
- Amount: {currency: USD, qualifier: exact|range|up_to|at_least|approximate|formula|not_published, value: decimal|null, minimum: decimal|null, maximum: decimal|null, period: semester|academic_year|calendar_year|one_time|total_program|summer|unknown, formula: text|null, valuation_year: text|null}
- cost_basis: base_tuition|resident_tuition|nonresident_tuition_increment|tuition_and_mandatory_fees|standard_room|standard_meal_plan|school_defined_coa|other|null; valuation_updates: tracks_current_cost|fixed_at_entry|fixed_dollars|unknown
- advertised_coverage_label: text|null, preserving the school's label; normalized_coverage: full_tuition|full_tuition_fees|tuition_housing_meals|full_school_defined_coa|partial_or_fixed|other|unknown, with no invented full-ride label
- included_in_package: boolean|null; optional_earned_income: boolean; supplemental_to_other_benefits: boolean|null; component renewal can differ
- amount_display_text: original short factual amount wording; no mandatory dollar conversion of tuition coverage

Range rules:
- Up to $20,000/year => qualifier up_to, maximum 20000, minimum null, period academic_year; zero is not a published minimum and $20,000 is not a guaranteed award
- $5,000–$15,000/year => qualifier range, minimum 5000, maximum 15000; at least $750 => at_least/minimum 750; approximately $50,000 current value => approximate with valuation year, distinct from cost coverage
- Full tuition => coverage full and appropriate cost_basis, amount not_published unless a dated official dollar value also exists; retain tuition as the promise and dollars as valuation
- One-time $10,000 enrichment => period one_time/total_program as stated, never multiplied by four; housing in year one and tuition for ten terms need separate durations
- Do not sum mutually exclusive variants, waivers already embedded in a package, NMSC sponsorship absorbed into housing, capped aid or optional work earnings; publish source totals separately as advertised_total_amount with scope/period rather than an unqualified computed value

Application/deadline fields:
- scholarship_application_requirement: required|encouraged|not_required|invitation_only|unknown; application_url: URL|null; essays/resume/recommendations/portfolio/audition: each required|conditional|not_required|unknown
- admission_plan_requirement: early_action|early_decision|any_plan|other|unknown; application_prerequisites: array of {kind, minimum_lead_days: integer|null, notes}; Ohio State portal delay is a real prerequisite
- milestones: array of {milestone_id: UUID, kind: admission_application|supporting_materials|scholarship_application|nomination|honors_application|aid_application|test_scores|first_choice_designation|campus_visit|interview|finalist_event|acceptance_deposit|award_notification, requirement: required|priority|recommended|invitation_only|unknown, applies_to_offer_ids: UUID[], date: date|null, range_start/range_end: date|null, time_local: time|null, timezone: IANA string|null, precision: day|month|date_range|recurring_month_day|not_published, source_date_text: text, entry_year: integer|null}
- interview_mode: in_person|virtual_live|virtual_asynchronous|multiple|unknown; finalist_attendance_required: boolean|null; event_travel_cost_coverage: text|null
- A recurring December 1 with no source year must remain recurring/unconfirmed for the next cohort, never silently become a dated deadline; priority and final deadlines are different milestones

Renewal/stacking/count fields:
- renewal_rules: array of {applies_to_benefit_ids: UUID[], minimum_gpa: decimal|null, gpa_basis: institution_cumulative|semester|major|other|unknown, credit_requirement: {minimum: decimal|null, period: term|academic_year|cumulative_by_year, milestones: object|null, eligible_credit_rules: text}, evaluation_timing: text, full_time_required: boolean|null, sap_required: boolean|null, honors_or_program_participation: text|null, service_hours: decimal|null, summer_remediation: allowed|not_allowed|unknown, probation_policy: text|null, appeal_policy: text|null, continuous_enrollment: boolean|null, deferment_policy: text|null}
- max_semesters/max_years: integer|null; extension_policy: text|null; undergraduate_to_graduate_use: boolean|null; graduation_ends_award: boolean|null
- stacking_rules: array of {other_aid_type: institutional_merit|institutional_need|external|nmsc|state|waiver|tuition_benefit|specific_program, other_program_id: UUID|null, relation: allowed|not_allowed|replaces|reduced_by_other_aid|counts_within_package|conditional|unknown, cap_basis: tuition|direct_costs|coa|other|null, cap_amount: Amount|null, notes: text}; avoid a single stackable boolean
- award_counts: array of {metric: offers|new_recipients|enrolled_scholars|target|finalists|share_of_entering_class, qualifier: exact|up_to|at_least|approximate|range|not_published, value/minimum/maximum: decimal|null, cohort_year: integer|null, denominator_description: text|null, scope: program|program_family|combined_programs, source_id: UUID}; target 50 offers, up to 44 winners and 340 scholars across all years are different facts

Evidence/quality fields:
- sources: array of {source_id: UUID, url: URL, resolved_url: URL, authority: official_program|official_financial_aid_policy|official_admissions|official_catalog|official_news|archived_official|lead_only, title: text, media_type: html|pdf|other, retrieved_at: timestamp, source_updated_at: timestamp|null, source_date_precision: day|month|year|unknown, content_sha256: text, normalized_text_sha256: text, normalization_version: text, etag: text|null, last_modified_header: text|null, archive_url: URL|null}

**D — Joining CDS and federal identity without creating false claims**

- Primary join: canonical institution_directory school_id and ipeds_id/NCES UNITID, with the existing slug crosswalk for aliases; no fuzzy name joins at request time; a scholarship at a specific campus must match that campus, not every institution sharing a system name; a named program can exist at a directory-only school with no CDS, so left-join aggregate data rather than require it
- One-to-many join: institution -> programs -> cohort versions/offers; current named-program entry_year is not the CDS canonical_year or the Scorecard data year; retain all three vintage labels and source links side by side
- Implemented H2A mapping in [merit migration](supabase/migrations/20260503120000_school_merit_profile.sql): H.2A01 -> non_need_aid_recipients_first_year_ft; H.2A02 -> avg_non_need_grant_first_year_ft; H.2A05/H.2A06 -> corresponding all-full-time-undergraduate metrics; H.201/H.214 supply denominators
- H2A recipient group: students with no financial need receiving institutional non-need scholarship/grant aid, excluding athletic awards and tuition benefits; the mean is for these recipients, not every entrant or everyone receiving a named merit award; a merit recipient with financial need can fall outside this group; H2A zero therefore does not establish absence of named merit programs
- Existing non_need_aid_share_first_year_ft = H.2A01 / H.201: percentage of all full-time first-year students who fit the H2A category, not percentage of no-need students winning aid and not applicant scholarship odds; keep numerator/denominator definitions visible
- H14 categories in schemas/cds_schema_2025_26.json: non-need H.1401–H.1410 are academics, alumni, art, athletics, job skills, ROTC, leadership, music/drama, religion and state/district residency; need-based H.1411–H.1419 parallel these except ROTC; these are school-level checkbox categories, not award names, thresholds, award counts or amounts
- Material implementation caveat: the current institutional_aid_academics flag ORs H.1401 and H.1411 at migration line 64; the schema explicitly distinguishes non-need and need-based criteria, so that flag cannot support the statement that a school checked academic non-need merit; proposed new integration should expose both separately or label the current combined field accurately; research-only task, no fix made
- The older PRD's illustrative H1/H5/H7 narrative is less reliable than the shipped H2A view plus canonical schema; implement against the actual definitions and document cohort labels

Suggested school presentation:
- Historical school-wide CDS panel: reporting year, no-need institutional recipients, denominator-qualified share and their average award, with exclusions and extraction quality
- Named program panel: entry cohort, required/priority deadlines, selection/consideration distinction, component coverage, who may apply, renewal and stacking, last verification and direct official link
- Separate federal affordability/outcomes panel: existing Scorecard/IPEDS data with vintage/definitions; link official net-price calculator
- Honest empty state: no verified named programs cataloged yet; no CDS reported or H2A missing remain separate coverage states
- Never claim a named award explains the H2A average, sum named recipient counts into H2A, infer a full-ride probability from published winner counts, subtract a merit award from average net price that may already include it, treat full tuition as all costs, or multiply an annual award by four without duration and renewal conditions
- Example explanatory copy pattern: in the cited CDS year, N of D full-time first-year students were reported in the no-financial-need institutional non-need grant category, with mean grant X among those recipients; below are separately documented programs for entering year Y, not estimates of an individual student's award

**E — Sourcing, copyright, license boundary and ethics**

- General US copyright conclusion: extracting scholarship facts such as amounts, dates, GPA thresholds, coverage and factual names into an independently structured dataset is generally viable; copyright distinguishes facts from the prose expressing them, and official educational status does not make a page public domain; paraphrase explanations and avoid copying marketing copy, essays, photographs, logos or entire tables verbatim [US Copyright Office](https://www.copyright.gov/help/faq/faq-protect.html)
- Compilations may protect original selection/arrangement, not underlying facts; avoiding copied third-party directory descriptions, selection and structure makes the independent provenance stronger [17 USC 103](https://www.govinfo.gov/content/pkg/USCODE-2024-title17/html/USCODE-2024-title17-chap1-sec103.htm)
- No universal safe word count or percentage for quotation; use only short, necessary evidence excerpts and links, with context and source attribution; the 25-word limit used by a research tool is not a legal safe harbor; sensitive verbatim material or whole-source mirroring needs separate rights assessment [Copyright Office fair-use guidance](https://www.copyright.gov/fair-use/more-info.html)
- Apply CC BY-SA 4.0 to the project's own eligible editorial synthesis, selection/arrangement and database rights where they exist; preserve attribution, license/version and change notices; raw uncopyrightable facts are not converted into exclusive property and their reuse may not trigger attribution/share-alike; source university text does not become BY-SA merely because extracted alongside our records; fair-use quotations cannot be relicensed as if we owned them [Creative Commons FAQ](https://creativecommons.org/faq/) and [BY-SA legal code, sections 2–4](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)
- Explicit content license boundary alongside MIT code, dataset author/attribution recipe and versioned source manifest; do not promise BY-SA compels every downstream use of every fact or automatically licenses application code; preserve third-party rights exclusions for excerpts/source files
- Third-party directories, counselor sheets and community reports: leads and change alerts only; follow the official school page and verify each claim independently; do not bulk import their editorial summaries or promote them to authority; an inaccessible official page means unverified/past-cycle, not license to substitute an unsourced current value
- Authority ranking should depend on field and applicable cohort: dated cohort-specific award terms for renewal/stacking, program calendar for current process, financial aid policy for overawards, official news for historical counts; newest fetch alone is not a conflict resolver; record both contradictory assertions for human review
- Public .edu access is not blanket crawl authorization; inspect applicable terms/access conditions and robots.txt for each host; use a descriptive user agent and contact URL, low per-host concurrency, caching, bounded allowlisted URLs, exponential backoff and Retry-After; do not bypass logins, CAPTCHAs, denials or application portals; a program policy can be publicly documented while student application records remain private
- Follow RFC 9309 semantics, including robots revalidation ordinarily within 24 hours and complete disallow on unreachable server/network errors; robots is not an access-authorization mechanism, so an allow rule does not waive other rights; honor published crawl-delay as an additional courtesy even though it is outside the standard [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html)
- Preserve document format and accessibility observations: text-readable versus scanned PDF, OCR needed, tagged/reading-order status if checked, extraction confidence and page/table locator; OCR is an extraction aid, not proof of accessible reading order or correct amount alignment; visually review eligibility/amount tables after OCR; offer accessible HTML factual summaries with descriptive source links and a PDF label [Section 508 scanned-PDF guidance](https://www.section508.gov/training/pdfs/aed-cop-pdf04/)
- Scholarship-level facts only: no student biographies, recipient contact details, application essays or applicant PII from official pages; no university endorsement implication, affiliate-driven ordering or financial-aid certainty; neutral correction route and an auditable review log

**F — Publication timing, cheap change detection and refresh policy**

Observed timing evidence, with inference clearly separated:
- [Ohio State historical application opening](https://honors-scholars.osu.edu/news/2021/07/27/eminence-fellows-program-application-open): next-entry-year competition opened July 27; historical evidence about timing, not current award terms
- [North Alabama current scholarship page](https://www.una.edu/admissions/new-freshmen/scholarships.html): Honors application opened August 1, 2026; 2027 award amounts subject to final funding October 1, 2026; initial opening and final funding can be different dates
- [Oklahoma current package](https://www.ou.edu/admissions/honors/scholarships/national-merit-finalist-scholarship/non-resident): explicit October 2026 update, still with mixed cohort/deadline years
- Current [Georgia Tech calendar](https://stampsps.gatech.edu/apply/calendar) and [Vanderbilt page](https://www.vanderbilt.edu/scholarships/signature/) give October–December 2026 application milestones and winter/spring 2027 selection; milestone dates are not page publication dates
- Operational inference from this sample: start next-cycle discovery in May/June, expect substantial July–October rollover activity before October–December admission/scholarship deadlines, and allow later clarification through November/December; no evidence for one universal month when all schools finalize next-year terms; spring/summer cost valuations and state funding may still change, so keep percentage/cost coverage distinct from dated dollar estimates

Staleness signals:
- Entry-year heading older than target cohort; conflicting heading/body/deadline years; a date whose weekday does not match; deadlines already past without a next-cycle explanation; old PDF cover/year versus newly updated HTML; terms explicitly tied to original-offer cohort; application coming soon after that cycle began; links to closed portals; missing funding language or renamed programs; a recently changed copyright footer or HTTP Last-Modified is weak evidence
- Concrete observed conflicts: OU Fall-2026 heading with 2026/2027 deadlines; GT April-2027 calendar versus March wording elsewhere; UCF 3-point-0 cohort table versus 3-point-2 FAQ; Tuskegee admissions versus renewal GPA; retain contradictory values and suppress confident actionable claims
- Old terms can remain valid for continuing award recipients; historical_only and current_cycle_unconfirmed are distinct from discontinued; 404 alone is not proof an award ended

Recommended cheap monitor:
- Maintain a small per-program authority URL set: program description, cohort terms, calendar, renewal policy and linked PDF; include parent landing-page link discovery so new yearly PDF filenames are found
- Conditional GET with ETag/If-None-Match and Last-Modified/If-Modified-Since when supported; 304 avoids transfer but does not itself establish correct cohort [HTTP semantics](https://httpwg.org/specs/rfc9110)
- Save fetch status, redirects and headers; hash raw bytes and separately stable main-content text; strip navigation/footer/cookie noise while preserving headings, table rows, footnotes, dates and negations; version normalization so a parser change does not look like an award change; hash/download linked PDFs separately
- When normalized content changes, run a deterministic semantic diff on amounts, coverage, dates, requirements, duration, selection and stacking; re-extract only changed sources; route material changes to a human before current publication, following the repository's reviewed-change precedent
- Supplement with [Internet Archive Availability/CDX APIs](https://archive.org/help/wayback_api.php) for prior official snapshots and [Save Page Now](https://archivesupport.zendesk.com/hc/en-us/articles/360001513491-Save-Pages-in-the-Wayback-Machine) where available; verify actual capture content/status, not just returned URL; record capture timestamp; archived pages support history, never prove current availability; honor archive service limits and do not assume JS/PDF captures are complete
- Any retained source captures remain separately rights-labeled; content-addressed snapshots and comparison metadata are useful audit evidence but do not resolve republication rights by themselves

Recommended cadence, a product policy rather than an empirically mandated interval:
- Full human re-verification at least annually for the next entry cohort, ideally August–September before early deadlines; move earlier for nomination/visit programs closing in September/October
- Automatic URL/text checks weekly July–January and monthly February–June; weekly also during an active interview/finalist/acceptance milestone window; cohort/amount/funding changes can happen between annual reviews
- Targeted deadline recheck 30 and seven days before each required/priority milestone; review material diffs promptly, and reverify sooner when a family/counselor correction or official change notice arrives
- If a current-cycle program still has no verified cohort terms by 30 days before its likely early deadline, flag needs_review and show the old terms as past-cycle rather than rolling forward dates; never replace missing publication with last year's guarantee
- Retain immutable prior versions and the date change was first observed; source_changed_at is observed time unless the school supplies an effective date; last_checked_at, last_human_verified_at and next_reverify_at remain separate
- Minimum freshness rule for families: display cohort, checked/verified dates, authority link and warnings inline; do not market a yearly refresh as a guarantee that every deadline stays accurate all year

**G — Principal failure modes and mitigations**

| Risk | Mitigation |
|---|---|
| Family treats a maximum or full-tuition label as a guaranteed full ride | Typed amount qualifiers, cost categories/exclusions, standard room/meal scope, remaining-cost caveat and conditional-versus-guaranteed language |
| Automatic consideration mistaken for automatic award | Independent selection_mode, consideration_route and explicit guarantee evidence; Tulsa/GT/Tuskegee canary examples |
| NMSF confused with NMF, NMSC award or first-choice designation | Separate status predicates and designation milestone; do not collapse an entire National Merit family into one flag |
| Test-optional admission implies scholarship eligibility without tests | Scholarship-specific test policy, official-report and score-composition rules, and separate test-free/score tiers; preserve school GPA definitions |
| Deadline year inferred incorrectly or optional step mistaken for required | Cohort-specific milestones, date precision, timezone only when evidenced, priority versus required, source-calendar precedence with conflict review |
| Need-plus-merit erased or need-only awards labeled merit | Independent aid_basis/need_role and FAFSA requirement; Karsh required need versus Vanderbilt need top-up; exclude need-only from merit filters |
| Packages double-count state aid, waived nonresident tuition or NMSC components | Benefit instruments, included_in_package, component relationships, caps and component-specific sources; no naive additive savings calculator |
| Program cut, funding constrained or terms changed mid-cycle | Status/version history, funds_limited, scheduled change checks and immediate correction review; clear official-page authority and no continued guarantee based on archives |
| Renewal oversimplified to GPA | Credit period, cumulative milestones, source of credits, evaluation date, participation, summer cure, appeal and semester limits; component-specific rules for OU |
| School/system/campus mismatch | Reviewed UNITID join and campus scope, existing identity guard/crosswalk conventions; no name-only join |
| Missing catalog entry misread as no school merit | Separate directory research coverage from verified absence; unknown remains unknown; allow programs without CDS and CDS without named programs |
| Named award counts misused as selection odds | Offer/recipient/enrolled/target metric, cohort and denominator scope; no inferred probability without comparable applicant pool |
| Promotional source looks current but mixes policies | Field-level evidence, source cohort and contradiction state; human publication review for high-impact fields and public correction channel |
| CC BY-SA overclaims ownership or imported-directory rights | Original synthesis, explicit third-party rights exclusions, independent official verification, documented contribution/licensing boundary |
| Corpus becomes selective-school/full-ride biased | Publish coverage by institution type/region and research status; treat the diverse cases above as taxonomy validation rather than representative prevalence estimates |

Suggested PRD acceptance gate: every published program has reviewed institutional identity, a genuine named program and administering authority, official source evidence, a cohort or explicit unconfirmed-cohort label, typed coverage and amount period, honest selection/application distinction, deadline precision and verification date; amount/deadline/eligibility conflicts cannot appear as confident current facts, and current aggregate CDS values never acquire a named-program or individualized interpretation.
